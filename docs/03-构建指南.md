# 构建指南

## 0. 前置

1. 部署 API 服务（见 `docs/02-API服务部署.md`）。
2. 准备对应开发环境（见下文各端）。

## 1. Android 端

### 环境
- Android Studio（Ladybug 或更新）+ JDK 17
- Android SDK：compileSdk 35

### 构建
```bash
cd android
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```
或直接用 Android Studio 打开 `android/` 目录，等待 Gradle 同步后点击 Run。

### 配置 API 地址
- 模拟器：设置页填 `http://10.0.2.2:3000`
- 真机：设置页填 `http://<电脑局域网IP>:3000`（见部署文档）

### 首次运行
1. 进入「设置 → 服务器地址」，填写 API 地址并保存；
2. 回到发现页，数据加载成功即网络正常；
3. 使用扫码登录或验证码登录（需真实手机号）。

## 2. HarmonyOS 端

### 环境
- DevEco Studio 5.0+（API 12+，Stage 模型）
- HarmonyOS SDK：API 12

### 构建
1. 用 DevEco Studio 打开 `harmony/` 目录；
2. 等待 hvigor 同步完成；
3. 菜单 `Build → Build Hap(s)/APP(s)`，或命令行：
   ```bash
   cd harmony
   hvigorw assembleHap
   ```

### 配置 API 地址
- 模拟器/真机：设置页填 `http://<电脑局域网IP>:3000`
- 真机需与电脑同一 Wi-Fi，并保证电脑防火墙放行 3000 端口。

### 说明
- `entry/src/main/resources/rawfile/legal/` 为法务文档内置文本（与 `docs/legal/` 同源）；
- 应用图标使用占位图，发布前请替换 `resources/base/media/` 下资源。

## 3. Windows 端

### 环境
- .NET 8 SDK：https://dotnet.microsoft.com/download

### 构建与运行
```bash
cd windows
dotnet build -c Release
dotnet run --project src/CloudMusic
# 或打开 CloudMusic.sln 用 Visual Studio 2022+ 运行
```

### 说明
- 需要 .NET SDK 10（本工程使用 `net10.0-windows`）；若使用 .NET 8 SDK，可将 `src/CloudMusic/CloudMusic.csproj` 的 `TargetFramework` 改为 `net8.0-windows` 后重新编译
- 播放依赖 LibVLC：NuGet 包 `VideoLAN.LibVLC.Windows` 会自动携带运行库；
- 首次运行如提示缺少运行库，请确认联网还原 NuGet 包；
- 系统媒体信息（SMTC）为尽力集成：在带 Windows SDK 投影的版本化 TFM（如 `net8.0-windows10.0.19041.0`）下自动启用，否则静默降级不影响功能；
- 法务文档内置在 `Assets/legal/`，与 `docs/legal/` 同源。
