# 架构说明

## 1. 总体架构

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  Android 端  │   │ HarmonyOS 端 │   │  Windows 端  │
│ Kotlin/Compose│  │ ArkTS/ArkUI  │   │  WPF/.NET8  │
└──────┬──────┘   └──────┬──────┘   └──────┬──────┘
       │                 │                 │
       └────────┬────────┴────────┬────────┘
                │   HTTP(S) + Cookie
        ┌───────▼────────┐
        │  API 服务(自托管) │  NeteaseCloudMusicApi (Node.js)
        └───────┬────────┘
                │
        ┌───────▼────────┐
        │  网易云音乐平台   │
        └────────────────┘
```

三端客户端通过统一的 HTTP 接口与自托管的 API 服务交互，登录凭证（Cookie）保存在各端本地，接口返回数据为 JSON。

## 2. 数据流

### 2.1 登录（扫码）

```
客户端 → POST /login/qr/key                     → 得到 unikey
客户端 → POST /login/qr/create?key=xxx&qrimg=true → 得到二维码 base64 图片（展示）
客户端 → 轮询 POST /login/qr/check?key=xxx       → 802(已扫码待确认) / 803(成功，返回 cookie)
客户端 → 保存 cookie → 调 /login/status 拉取用户信息
```

### 2.2 登录（手机验证码）

```
客户端 → POST /captcha/sent?phone=xxx         → 发送验证码
客户端 → POST /captcha/verify?phone=&captcha= → 校验验证码
客户端 → POST /login/cellphone?phone=&captcha= → 登录成功，返回 cookie
```

### 2.3 播放

```
客户端 → POST /song/url/v1?id=xxx&level=exhigh → 得到直链 url
客户端 → 播放引擎（ExoPlayer / AVPlayer / LibVLC）拉流播放
播放失败（VIP/版权受限）→ 自动降档重试（exhigh→higher→standard）
```

### 2.4 歌词

```
客户端 → POST /lyric?id=xxx → lrc(原词) / tlyric(翻译) / romalrc(罗马音)
客户端 → LRC 解析 → 按播放进度高亮当前行；支持偏移、字号、DIY 替换
```

## 3. 三端模块映射

| 模块 | Android | HarmonyOS | Windows |
|---|---|---|---|
| 网络 | Retrofit/OkHttp/Gson + CookieJar | @kit.NetworkKit http + preferences | HttpClient + CookieContainer |
| 设置 | DataStore Preferences | preferences | JSON 文件 |
| 播放 | Media3 ExoPlayer 单例 | media.AVPlayer 单例 | LibVLC MediaPlayer |
| 系统媒体 | MediaSessionService（锁屏通知） | AVSession（媒体中心） | SMTC（尽力集成） |
| 歌词解析 | LrcParser.kt | LrcParser.ets | LrcService.cs |
| UI | Compose + Navigation | ArkUI 页面 + router | WPF + MVVM |

## 4. 关键设计

- **Cookie 透传**：三端均持久化登录 Cookie，所有请求自动携带，实现"与网易云平台真实连接"。
- **音质降档**：`/song/url/v1` 返回的直链可能因版权/VIP 为空，播放器按 `lossless→exhigh→higher→standard` 自动降级重试。
- **歌词对齐**：原词与翻译按时间戳对齐；DIY 歌词支持用户导入任意 LRC 文本并整体偏移。
- **主题定制**：6 种预设色板 + 深色模式，主题色即时生效并持久化。
- **法务同源**：`docs/legal/*.md` 为唯一事实源，三端内置展示相同全文。
