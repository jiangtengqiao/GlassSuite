# 服务端说明

本目录为「乐云音乐 CloudMusic」的 API 服务部署配置，基于开源项目 [NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi)（MIT）。

## 快速开始

```bash
# Docker（推荐）
docker compose up -d

# 或源码运行
bash start.sh          # Linux/macOS/Git Bash
.\start.ps1            # Windows PowerShell
```

## 验证

```bash
curl "http://localhost:3000/personalized?limit=3"
```

返回 JSON 且 `code == 200` 即正常。

## 三端默认地址

| 端 | 默认地址 |
|---|---|
| Windows | http://localhost:3000 |
| Android 模拟器 | http://10.0.2.2:3000 |

## 端口修改

- Docker：编辑 `docker-compose.yml` 的 `ports` 映射；
- 源码：`PORT=3001 node app.js`（或设置环境变量）。

修改后请在应用「设置 → 服务器地址」同步更新。
