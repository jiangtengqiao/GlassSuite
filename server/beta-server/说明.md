# GlassSuite 开发者尝鲜系统（Beta 申请服务）

独立于网易云接口的轻量服务：**自动评分筛选申请 → 签发 22~37 位唯一尝鲜码 → 实时比对 → 按权限推送 Beta/正式版**。

## 启动

```bash
cd server/beta-server
npm install --registry=https://registry.npmmirror.com
node server.js          # 默认端口 3100（环境变量 BETA_PORT 可改）
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/requirements` | 申请要求（应用内明了展示） |
| POST | `/apply` | 提交申请，自动评分（满分 90，≥60 通过并签发尝鲜码） |
| GET | `/status?email=` | 查询申请状态 |
| POST | `/verify` | 尝鲜码实时比对 `{key}` |
| GET | `/latest?key=` | 权限检查（beta 渠道 / 仅正式版） |

## 评分规则（自动排列与筛选）

- 邮箱有效性 10 + 填写完整性 20 + 用途权重 20（开发者 20/测试 15/媒体 10/普通 5）+ 理由深度 25（≥30 字 25 分，≥15 字 15 分）+ 关键词命中 15
- **实时判定**：得分 ≥ 60 → 通过并签发尝鲜码；否则驳回并附原因；已申请的邮箱重复提交直接返回原结果
- 尝鲜码：22~37 位随机字符（去除易混淆字符集），唯一性校验，永不重复

## 三端集成

应用「设置 → 开发者尝鲜」：展示要求 → 填写申请 → 实时结果（通过显示尝鲜码 / 驳回显示原因）→ 输入尝鲜码激活 → 更新中心按权限推送 Beta 或正式版。

## 说明

- 数据存储于 `data/applications.json`（明文存储仅用于演示；正式部署请接数据库并加密密钥）
- 应用内 Beta 服务地址默认 `http://localhost:3100`（Android 模拟器 `http://10.0.2.2:3100`），可在设置中修改
