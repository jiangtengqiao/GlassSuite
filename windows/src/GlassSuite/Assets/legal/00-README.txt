# 法律与合规文档 — 维护说明

本目录是「璃光 GlassSuite」双端应用（Android / Windows）**法律文档的唯一事实源**，每篇约 3 万字。

三端应用内的「设置 → 关于与法律」页面均展示本目录文档的全文内容。修改法律文档时，只需更新本目录文件，并同步三端内置文本。

## 文档清单

| 编号 | 文件 | 说明 |
|---|---|---|
| 01 | 用户协议.md | 服务使用总协议（账号、知识产权、违约、争议解决） |
| 02 | 隐私政策.md | 个人信息收集、使用、共享、存储与用户权利 |
| 03 | 儿童个人信息保护规则.md | 针对 14 周岁以下用户的特别规则 |
| 04 | 版权声明与侵权投诉.md | 版权归属、用户承诺、通知-删除流程 |
| 05 | 免责声明.md | 第三方接口、不可抗力、信息准确性等免责条款 |
| 06 | 第三方SDK与权限清单.md | 三端及服务端使用的组件、权限、数据与许可证 |
| 07 | 账号注销指引.md | 注销条件、流程、后果与时限 |
| 08 | 投诉与举报.md | 受理范围、渠道、时限与申诉 |
| 09 | 用户行为规范.md | 禁止行为清单与违规处理 |

## 同步发布流程

1. 修改本目录对应 `.md` 文件；
2. 同步至三端内置文本（Android `assets/legal/`、Windows `Assets/legal/`，扩展名 `.txt`）；
3. 在应用「设置 → 关于与法律」核对展示；
4. 随应用版本一同发布。

> 本套文本为通用模板，不构成法律意见；正式运营前请由专业法务审核并依据适用法律法规调整。
