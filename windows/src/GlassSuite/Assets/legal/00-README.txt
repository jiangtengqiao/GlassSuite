# 法律与合规文档 — 维护说明

本目录是「乐云音乐（CloudMusic）」三端应用（Android / HarmonyOS / Windows）**法律文档的唯一事实源**。

三端应用内的「设置 → 关于与法律」页面均展示本目录文档的全文内容。修改法律文档时，只需更新本目录文件，并在发布时同步三端内置文本（发布流程见文末）。

## 文档清单

| 编号 | 文件 | 说明 |

| 01 | 用户协议.md | 服务使用总协议（含账号、知识产权、违约、争议解决） |

| 09 | 用户行为规范.md | 禁止行为清单与违规处理 |

## 发布前必须替换的占位符

以下占位符在正式发布前必须替换为真实信息：

- `XXXX网络科技有限公司` → 运营主体工商登记全称
- `service@example.com` → 真实联系邮箱（建议企业域名邮箱）
- `400-XXX-XXXX` / `12345` 类号码 → 真实客服电话
- `20XX年XX月XX日` → 各文档实际生效日期
- 各文档末尾「更新日期」→ 实际发布日期
- 备案号/许可号（如有）→ 实际 ICP 备案号等

## 同步发布流程

1. 修改本目录对应 `.md` 文件；
2. 将正文同步至三端内置文本：
   - Android：`android/app/src/main/assets/legal/` 下同名文本文件；
   - HarmonyOS：`harmony/entry/src/main/resources/rawfile/legal/` 下同名文本文件；
   - Windows：`windows/src/CloudMusic/Assets/legal/` 下同名文本文件；
3. 在应用「设置 → 关于与法律」页面核对展示与排版；
4. 记录版本变更，随应用版本一同发布。

> 说明：本套文本为通用模板，不构成法律意见。正式运营前请由专业法务/律师审核，并依据目标市场的法律法规（如《个人信息保护法》《网络安全法》《未成年人保护法》及 GDPR 等，若适用）进行调整。
